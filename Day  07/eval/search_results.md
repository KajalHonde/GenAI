# AapdaMitra Semantic Search Results

This report is generated by `python -m eval.run_search_eval`.

It will contain the top matching chunks for each of the 10 evaluation questions,
including each hit's title, source filename, page number, similarity score and text.

Do not manually invent search hits. Add the AapdaMitra source documents to
`documents/`, run the indexing command, and then run the evaluation command.
