# AapdaMitra - Final Prompt Evaluation Report

## 1. Objective

The objective is to compare two system prompts
for the AapdaMitra disaster management assistant.

## 2. Model Used

Groq Model: openai/gpt-oss-120b

## 3. Testing Details

- Prompt A: Basic Disaster Assistant Prompt
- Prompt B: Improved AapdaMitra Prompt
- Total questions: 10
- Total responses: 20
- Topics: Earthquake and Flood

## 4. Evaluation Criteria

1. Accuracy
2. Safety
3. Relevance
4. Clarity
5. Valid JSON

Each criterion is scored out of 5.

## 5. Evaluation Results

Prompt A:
- Total Score: 234/250
- Average: 23.4/25
- Percentage: 93.6%

Prompt B:
- Total Score: 232/250
- Average: 23.2/25
- Percentage: 92.8%

## 6. Comparison

Prompt B achieved a slightly higher accuracy score.
Prompt A achieved a higher safety score.
Both prompts provided relevant and clear answers
and generated valid JSON responses.

## 7. Conclusion

The evaluation shows that both prompts perform
well in answering earthquake and flood-related
questions.

However, Prompt B did not achieve a higher
overall score than Prompt A.

Further improvements are required in safety
instructions, emergency guidance and uncertainty
handling before selecting the final production prompt.
